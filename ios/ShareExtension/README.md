# iOS Share Extension — "Save to DROP"

This folder contains the complete, real Share Extension for iOS:

- `ShareViewController.swift` — extracts URL / text / images from the share
  sheet and hands them to the DROP app via `drop://share?key=…`.
- `Info.plist` — extension declaration + activation rules (web URLs, text,
  up to 10 images, files).

The Android share receiver is already fully wired (see
`android/app/src/main/java/com/drop/memory/IncomingSharePlugin.java`). On iOS,
a Share Extension is a separate app-extension target that can only be added
through Xcode (the `.pbxproj` for a whole new target is generated by Xcode,
not by hand). The DROP app side of the handoff is already implemented in
`ios/App/App/SceneDelegate.swift` — it reads the payload and opens the capture
preview.

## One-time setup (Xcode, macOS)

1. Open the project:

   ```bash
   bun run mobile:open:ios
   ```

2. **Add the extension target**
   - File → New → Target… → search **Share Extension**.
   - Product Name: `ShareExtension`
   - Team: your Apple Developer team. Bundle identifier:
     `com.drop.memory.ShareExtension`.
   - Make sure **Embed in Application: App** is selected.
   - Xcode creates `ShareExtension/` with a template `ShareViewController.swift`
     and `Info.plist`.

3. **Replace the template files** with the ones in this folder:
   - Replace `ShareExtension/ShareViewController.swift` with
     `ios/ShareExtension/ShareViewController.swift`.
   - Replace `ShareExtension/Info.plist` with `ios/ShareExtension/Info.plist`.
   - Delete the template `Assets.xcassets`/`MainInterface.storyboard` if the
     target doesn't use them (this extension draws its own view).

4. **Enable the App Group** on both targets (required for image sharing):
   - Select the **App** target → Signing & Capabilities → + Capability →
     **App Groups** → add `group.com.drop.memory`.
   - Repeat for the **ShareExtension** target with the same group.
   - Without this, text/URL sharing still works (it travels inline in the
     deep link); image sharing needs the App Group.

5. **Deployment target**: set the ShareExtension deployment target to the
   same minimum as the App target (iOS 13+).

6. **App Groups entitlements**: Xcode creates
   `App.entitlements` and `ShareExtension.entitlements` automatically.

## How the handoff works

```
Safari / Photos / Files → Share → "Save to DROP"
  → ShareViewController extracts URL/text/images
  → writes payload to group.com.drop.memory/share/<key>/
  → opens drop://share?key=<key>
  → SceneDelegate (App target) reads the payload
  → injects window.dispatchEvent(new CustomEvent("drop:open-incoming-share",
    { detail: { text, url, imageDataUrl } }))
  → the web capture preview opens with the shared item → "Save to DROP"
  → the existing DROP AI pipeline (analysis, OCR, embeddings) runs
```

## Testing

1. Build & run the App on a simulator or device (the extension is embedded).
2. Open Safari → share sheet → the **DROP** icon appears in the actions row.
3. Share a page → the app opens with the link pre-filled in the capture screen.
4. Share a photo from Photos → the app opens with the image preview.
5. Confirm the Drop is saved, analyzed, and searchable.
